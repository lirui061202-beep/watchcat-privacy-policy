萌猫小屋隐私政策

更新及生效日期：2026年11月2日

萌猫小屋是一款面向鸿蒙智能手表的猫咪互动陪伴应用。本政策说明您使用本应用时涉及的信息、用途、保存方式和联系渠道。首次使用时，您可查看完整政策，选择同意后进入应用；不同意则退出。

一、保存在手表上的信息

本应用在应用私有存储中保存隐私同意状态、已拥有的猫咪及名字、房间安排、陪伴与照料记录、应用内金币和罐头、签到进度、偏好设置以及已解锁内容，用于恢复您的小屋状态。猫咪照片由应用内素材合成并保存在应用私有目录，不调用摄像头拍摄，也不读取您的系统相册。

本应用读取设备当前时间，用于昼夜场景、猫咪需要和每日签到。上述陪伴数据由应用在本地处理，当前版本未设置开发者自有服务器来收集这些记录，未接入广告或第三方行为分析服务。

二、华为应用内支付

购买猫咪组合或房间、查询商品价格及恢复购买时，本应用使用华为应用内支付服务（IAP Kit）。华为按其服务条款及隐私声明处理账号、订单和支付相关信息。本应用接收并验证商品标识、订单标识、购买凭证、购买状态等信息，用于发放已购内容、保存权益、防止重复发放及恢复购买；已购内容权益保存在应用本地存档中，交易记录由华为服务管理。本应用不直接获取您的支付密码或银行卡信息。

支付流程可能需要网络和已登录的华为账号。您可在华为提供的支付界面查看相应隐私说明及管理订单。购买属可选功能，不购买也可使用基础陪伴内容。

三、权限及设备功能

本应用声明振动权限（ohos.permission.VIBRATE），仅在前台互动中提供轻微触感反馈。当前版本不申请定位、通讯录、麦克风、相机或系统相册读取权限。应用在前台显示时使用系统保持亮屏功能。

四、保存、删除与信息安全

应用使用系统私有存储隔离数据，并校验本地存档和支付凭证。请妥善保管您的手表及华为账号。本地记录通常随应用使用保留；卸载应用或通过系统清除应用数据会移除本地陪伴记录、照片和同意状态，且未必能够恢复。卸载不等于删除华为侧的交易记录；已购非消耗型内容可通过应用内“恢复购买”尝试恢复，具体以原购买账号和华为服务返回的有效权益为准。

如需了解、处理与本应用有关的信息问题，请通过下方邮箱联系。对于仅存在您设备上的数据，我们不能远程读取或直接替您删除。通过邮件联系我们时，我们会接触您主动提供的邮箱地址及问题内容，仅用于答复和处理该请求；请勿发送密码、验证码或完整付款凭证。

五、第三方及政策网页

除上述华为支付服务外，当前版本不主动向其他第三方发送您的陪伴存档。本政策网页使用 GitHub Pages 托管，访问网页时托管服务可能处理 IP 地址及请求日志，以提供和维护网页服务，详见 GitHub 隐私声明。本页不包含广告、追踪脚本或外部统计代码。

六、未成年人

未成年人应在监护人指导下阅读本政策和使用本应用，涉及付费时应取得监护人同意。若监护人对未成年人使用本应用或相关信息处理有疑问，可联系我们。

七、政策更新与联系

若信息处理方式发生变化，我们将更新本政策及日期，并根据实际变化在应用中提供必要提示。您可随时通过应用中的隐私政策入口查看本页。
